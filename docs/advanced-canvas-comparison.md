# Сравнение Miro Canvas и Advanced Canvas

Дата сверки: **07.10.2026**. Miro Canvas: **0.2.10**, по [manifest.json](../manifest.json).
Advanced Canvas: **7.1.0**, минимум Obsidian 1.13.0, по [официальному manifest](https://raw.githubusercontent.com/Developer-Mike/obsidian-advanced-canvas/main/manifest.json) и [релизу 7.1.0](https://github.com/Developer-Mike/obsidian-advanced-canvas/releases/tag/7.1.0).
Основа списка — сообщение пользователя и [официальный README тега 7.1.0](https://github.com/Developer-Mike/obsidian-advanced-canvas/blob/7.1.0/README.md). Технические уточнения ниже ссылаются также на официальные исходники `main`, просмотренные этой датой; их не следует считать отдельной проверкой кода релизного тега.

**Полностью** — есть собственный пользовательский аналог основной возможности; **Частично** — есть работающая часть, но остаётся указанный пробел; **Нет** — собственной реализации не найдено. Оценка по исходникам и регистрации интерфейса, без запуска приложений или тестов в рамках этого сравнения. Доступные нативные функции Obsidian обозначены отдельно.

[AdvancedCanvasAdapter](../src/advanced-canvas-adapter.ts) обнаруживает чужой плагин, читает его данные и предоставляет защитные обёртки. [inspectAdvancedCanvas](../src/canvas-session.ts#L239) делает диагностическую инспекцию. Это не реализация функций Advanced Canvas. [Импортёр](../src/importers/advanced-canvas.ts) создаёт совместимую копию и переводит поддерживаемые стили в `miroCanvas`; сохранение чужого поля само по себе не включает его поведение. Сравнение относится к Miro Canvas без установленного Advanced Canvas.

## Приоритеты пробелов

1. **Связь досок с базой знаний:** metadata cache, свойства `.canvas`, ссылки/эмбеды отдельных карточек, перенос outgoing/backlinks и автоматические связи. Это отдельный отсутствующий слой, не задача расширения read-only адаптера.
2. **Повседневное редактирование:** шаблоны, автоматическая высота, раскрытие/сворачивание групп; выбор связанных линий, их подсветка, настоящий Flip Edge, floating ends и недостающие команды. PNG/SVG — отдельный полезный экспорт, PDF/PPTX его не заменяют.
3. **Специализированные сценарии:** порталы с междосочными связями, аннотация PDF-страниц, инкапсуляция, Focus Mode, редактор/ветвление презентаций, A*, CSS-атрибуты и публичные события. Переменные breakpoints и расширение readonly/defaults стоит планировать по реальным задачам и нагрузке больших досок.

Эти приоритеты — предложение для следующего планирования, а не обязательство копировать весь Advanced Canvas. Совместимость сохранённых данных, наличие интерфейса и проверенная работа в Obsidian — три разные оценки; эта таблица фиксирует первые две по коду и не утверждает проверку третьей.
