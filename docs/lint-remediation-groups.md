# Оставшиеся предупреждения: группы и порядок исправления

Снимок от 2026-10-06 для кода `96420fa` (0.2.7). Исполняемый код при этом
разборе не изменён. Свежий `npm run lint:report`: **0 ошибок, 332 предупреждения
в `src/`**. CSS: **83 `!important`, 0 `:has`**. Это количество диагностик,
а не количество независимых багов: одно использование `any` может породить
несколько сообщений на одной строке.

[Полный перечень](lint-remaining-sites.json) содержит **438 записей**:
332 исходного кода плагина, 83 CSS и 23 отдельного MCP-сервера. У каждой записи
есть группа, файл, актуальная строка; у TypeScript — правило, контекст объявления
и фрагмент кода, у CSS — селектор и свойство. Хеши 51 файла позволяют обнаружить
устаревший снимок. Номера строк исходного пользовательского отчёта уже сместились.
Версии локальной проверки: ESLint 9.39.5, eslint-plugin-obsidianmd 0.4.2,
TypeScript 5.9.3, декларации SDK Obsidian 1.13.1.

MCP исследован отдельно теми же правилами, с корректными Node globals. Получены
21 предупреждение и 2 ошибки диагностического набора правил плагина; обе ошибки
относятся к перенаправлению console в stderr. Они не являются ошибками
`npm run lint` для самого плагина. Конфигурация линтера не изменялась, правила
не отключались. Ошибки `no-undef` для стандартных `process`/`Buffer`, возникающие
при применении браузерного окружения к Node-серверу, не включены в снимок.

### S1: 166 — исправлять по пути данных

Правила: `no-unsafe-member-access` **78**, `no-unsafe-assignment` **62**,
`no-unsafe-argument` **22**, `no-unsafe-call` **2**, `no-explicit-any` **1**,
`no-unsafe-return` **1**. Итого ровно 166, без двойного учёта.

- **board-selection.ts — 69.** `Loose = Record<string, any>`, чтение native
  edges/localOverrides, перенос выбранных концов, waypoints, комментариев и
  связей. Preview и commit используют один путь данных. Нельзя просто
  объявить все поля обязательными или переносить всю линию вместе с одним концом.
- **canvas-authoring.ts — 58.** Создание/изменение карточек, линий, стилей,
  копирование и запись документов. Уточнять проверенные записи на границах,
  сохраняя нативный механизм истории и неизвестные поля.
- **Остальные модули — 39.** Адаптеры, импорт, M1, source renderer,
  MetadataWriter/store, комментарии, геометрия, viewport. Причины включают
  `Array.isArray` с типом any[], `Reflect.apply` с результатом any и неполные
  типы изменяемых JSON-объектов. Диагностика сама по себе не доказывает
  отсутствие проверки в работающем коде.

Обязательная проверка: смешанное выделение, отдельные концы пересекающей линии,
повторный drag, группа и zoom; пути прикреплённых линий **до отпускания**;
commit/cancel/Undo/Redo; блокировки и review; импорт и неизвестные поля на всех
уровнях, неизменный `miroSource`; hostile/revoked Proxy и бросающие getters;
большая доска без дополнительной работы на каждую карточку в каждом кадре.
Если меняются только типы, доказать эквивалентность unminified и production
сборок. Новые проверки входных данных требуют отдельной поведенческой проверки.

### S2: 113 — разбирать по семействам DOM

Больше всего в M2 tools (**35**) и перестановке панелей (**18**); ещё **60**
в 19 остальных модулях: экспорт, поиск, комментарии, подписи связей, редактор,
шрифты, панели, курсор, выделение и слайды.

`document.createElement` — стандартный способ создания элемента; предупреждение
здесь требует соглашений Obsidian, а не сообщает о сломанном DOM. Сначала
мигрировать общие фабрики одного компонента, затем самостоятельные создания.
Глобальная замена на helper текущего окна может вставить элемент в другой
документ. Отдельно проверять SVG namespace и тестовые документы без расширений
Obsidian; не маскировать предупреждение перестановкой имени метода в строку.

Обязательная проверка: обе темы, keyboard/focus, мобильная клавиатура, hover,
disabled/hidden, нажатие и отмена drag, сворачивание/перестановка панелей,
выделение/ручки/подписи, комментарии, export/PDF, выгрузка/reload. Окно-владелец
и дополнительные окна проверять отдельно; нативные и синтетические результаты
не объединять. Сохранить tablet-padding через `--miro-canvas-button-padding`.

### S3: 14 — сохранить ограничения валидаторов

anchors, appearance (2), attachment-labels, canvas-elements, device-files,
document-viewer (2), local-comments (3), main, metadata, settings.

Проверки намеренно запрещают управляющие символы в ключах, путях, именах,
подписях и псевдонимах авторов. Удаление regex сняло бы предупреждение,

### S4: 12 — отделить владельца окна от среды выполнения

- **Таймеры main — 3:** повторная инициализация ещё не готового Canvas и её
  отмена при смене leaf/выгрузке. Нужна стабильная пара постановки/отмены.
- **Таймеры PDF — 2:** ограничение ожидания native viewer до 2 секунд и очистка
  после resolve/reject/timeout, включая закрытую вкладку.
- **globalThis — 7:** fallback поиска, fallback document в M1 (2), QuickTools,
  SourceRenderer, тестовый адрес font pack, генератор Canvas ID.

Особый случай: `canvas-ids.ts` импортируется и плагином, и `mcp/src/tools-edit.ts`.
Замена `globalThis.crypto` на `window.crypto` сломает сервер без DOM. Генератор
должен сохранять криптографические ID из 16 hex-символов в обеих средах.
У font packs глобальное поле — управляемый тестовый endpoint; обычные загрузки
по-прежнему возможны только по нажатию. Нельзя потерять этот путь проверки.

Обязательная проверка: задержанное монтирование, быстрое переключение файлов,
unload/reload до срабатывания, готовый/не готовый/ошибочный PDF viewer;
поиск с debounce и закрытием; Node/MCP ID; окно-владелец; обе Android модели.
Font-pack проверки используют существующий тестовый endpoint, без непрошеных
загрузок реальных пакетов.

### S5: 14 — три разных причины

**activeLeaf — 11 в main.** Работа с активной доской, проверка продолжения retry,
пересборка после настроек, импорт, меню и инструменты. Getter view не заменяет
идентичность leaf во всех этих местах. Сначала разделить получение view,
открытие файла и проверку всё ещё активного leaf.

**DOM helpers — 2:** editor-appearance проверяет наличие createElement у документа
iframe; M1 ищет подпись/метку результата поиска querySelector. Пометки приходят
из деклараций SDK Obsidian; это не утверждение, что стандартный querySelector
вообще удалён из браузера. Сохранить capability probe и документ-владелец.

**execCommand — 1:** запасной путь Cut/Copy/Paste после попытки Electron bridge.
Простая замена на navigator.clipboard не повторяет синхронное редактирование,
вырезание и нативную историю. Обязательны обычный текст, выделенный фрагмент,
Canvas-граф с метаданными, клавиатурные команды/меню, mobile fallback и отказ
при недоступном буфере. Только реальные проверки с нужным видом ввода подтверждают
работу буфера; синтетический ClipboardEvent не доказывает системный clipboard.

### S6: 5 — единая миграция настроек

`getSettingDefinitions` отсутствует (**1**); повторный `display()` отмечен
правилом (**1**) и deprecated (**1**); setWarning (**1**) и setDynamicTooltip
(**1**) также помечены SDK. Стандартные определения нужны для поиска настроек
Obsidian; нынешний imperative display строит большой экран с сохранением scroll.

Не заменять методы по одному без проверки структуры. Сохранить все значения,
RU/EN ключи, навигацию по секциям, шрифты/авторов/инструменты, порядок списков,
сохранение/повторный render без прыжка scroll и фокуса. Проверить встроенный поиск
на поддерживаемых версиях, sliders и destructive font removal.
Телефон сейчас имеет Obsidian 1.12.7, ниже minAppVersion 1.13.7: его проверки
полезны как дополнительная legacy-проверка, но не заменяют проверку новых API
на заявленных версиях. Приложение/manifest этим разбором не обновляются.

### S7: 2 — явно определить допустимое строковое значение

comments-panel.make преобразует unknown в текст; M1 читает node.text для
определения HTML при форматировании фрагмента. Уточнить ожидаемые значения,
не показывать произвольный `[object Object]` и не вызывать неожиданную
пользовательскую toString. Проверить отсутствующие/строковые/числовые/ошибочные
значения, комментарии, Markdown/HTML и сохранение исходного текста.

### S8: 3 — маленькая группа с разным риском

- **minimap-model:35:** пустой MinimapViewportSize extends ViewportSize.
  Кандидат для type alias с проверкой minimap/viewport и идентичности сборки.
- **appearance:1231:** unsafe key получает тип never после отрицания type guard
  на уже строковом ключе. В runtime ключ остаётся строкой, которая не прошла
  ограничения. Сохранить ветку диагностики; не удалять её как недостижимую.
- **M1:8962:** alias session=this нужен обёртке, где `this` — исходный native
  receiver. Arrow/bind могут подменить receiver. Если реорганизовывать, проверить
  args/result/this, историю, blocked edits, dispose и более поздний чужой hook.

### S9: 3 — совместимость команды и диагностическое имя

`m1-commands` вызывает предупреждение о слове command в ID. Оно уже является
ID зарегистрированной команды: бездумное переименование потеряет пользовательские
hotkeys/ссылки. Нужен совместимый путь миграции или объяснение стабильного ID.
Два sentence-case сообщения относятся к строкам `miro-canvas` и
`miro-canvas · Canvas` в status bar, включаемом **только для developer diagnostics**.
Не менять имя продукта ради автомата; оценить здесь требования к диагностике.
