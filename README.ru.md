# Miro Canvas

**Доска для ваших заметок Obsidian с инструментами в духе Miro.**

Планируйте на стикерах, стройте схемы, рисуйте и оставляйте комментарии прямо
в обычном Canvas. Добавляйте заметки и вложения из хранилища, соединяйте их
стрелками. Доска остаётся локальным файлом `.canvas`.

[English](README.md) · [Установка](#установка) · [Быстрый старт](#быстрый-старт) · [Руководство](docs/guide.ru.md) · [Выпуски](https://github.com/NixWrk/Obsidian-Plugin---Miro-Canvas/releases)

## Что можно делать

| Задача | Возможности |
| --- | --- |
| **Планировать** | Стикеры, текст, фигуры, блок-схемы и фреймы, которые перемещаются вместе с содержимым. |
| **Работать с заметками** | Заметки хранилища, `[[ссылки]]`, встраивания, изображения, PDF, блоки кода и таблицы Markdown. |
| **Связывать идеи** | Прямые, ломаные и изогнутые стрелки с подписями. Прикреплённые линии следуют за карточками. |
| **Рисовать** | Перо, маркер, распознавание фигур и ластики для удаления целого штриха или его части. |
| **Обсуждать** | Комментарии, ответы, отметки «решено», блокировка элементов и режим просмотра доски. |
| **Настраивать под себя** | Шрифты, цвета, светлая и тёмная темы доски, подвижные панели, порядок инструментов, поиск и миникарта. |
| **Делиться результатом** | Экспорт в PDF и PowerPoint: страницы вручную или по фреймам. |

Расположение панелей и набор инструментов запоминаются отдельно для
компьютера, планшета и телефона. На Android доступны жесты, рисование
стилусом и, по желанию, пальцем. Интерфейс — на русском и английском.

Экспорт рисует отдельный снимок данных без захвата экрана: можно продолжать
редактирование или открыть другую доску. Файлы сохраняются как новые вложения
в хранилище. В растровом PDF/PPTX каждая страница — изображение доски.
В рабочей версии добавлен выбор **«Растровый / Векторный»** для PDF и PowerPoint;
SVG остаётся отдельным, всегда векторным форматом. PDF заменяет шрифты на
встроенный Noto Sans с четырьмя начертаниями. В векторном PowerPoint каждый
слайд содержит SVG и запасное JPEG-изображение для старых просмотрщиков;
текст и фигуры не становятся отдельными объектами PowerPoint. Веб-встраивания
и видео не экспортируются. [Режимы и проверки](docs/vector-viewing-acceptance.md).

## Расширение Canvas в 0.3.0

**Тема доски:** «Как в Obsidian» повторяет текущую светлую или тёмную тему Obsidian, даже если тема устройства отличается. Явные варианты «Светлая» и «Тёмная» остаются независимыми. Длинные подписи меню переносятся внутри его границ.


Меню **«Ещё»** над выделением показывает действия с подписями: порядок слоёв, действия с доской и команды Canvas. Удаление находится в конце.

Версия 0.3.0 добавляет следующие возможности досок. Проверки в приложении
и оставшиеся сценарии проверки записаны в
[план](docs/canvas-enhancement-plan.md) и
[проверки интеграции](docs/obsidian-integration-checks.md).

| Возможность | Поведение и ограничения |
| --- | --- |
| **Поиск в связанных заметках** | Поиск по доске учитывает содержимое Markdown-карточек файлов и фрагменты заголовков/блоков; есть учёт регистра и ограниченный режим регулярных выражений. |
| **Связи** | Команда **Развернуть направление связи** (Flip), выделение входящих, исходящих и всех связанных линий, а также подсветка без изменения выделения. |
| **Компактные группы** | Сворачивание меняет представление; настоящие карточки, связи и сохранённые координаты остаются в файле. |
| **Перенос выделения** | Карточки и внутренние линии переходят в новую доску, внешние линии прикрепляются к её карточке файла. Undo восстанавливает выделение на исходной доске, сохраняя новый файл. |
| **Свойства доски и ссылки на карточки** | Редактирование свойств, тегов и псевдонимов; копирование ссылки или встраивания отдельной карточки. Поддерживаемая интеграция использует временный кэш и обратимые обработчики панелей для графа, исходящих и обратных ссылок. |
| **Связи из свойств заметок** | Необязательное создание линий между карточками файлов по ссылкам в свойствах заметок; ручные линии сохраняются. |
| **Общие цвета и стили** | Постоянная палитра используется для досок без собственной изменённой палитры. Именованные CSS-объявления применяются локально из ограниченного набора. |
| **Содержимое при масштабировании** | Пороги для текста, файлов, веб-карточек и Miro-карточек; выделенные и редактируемые карточки остаются читаемыми. |
| **Углы карточек** | Радиус от 0 до 48 пикселей доски: ползунок и точное числовое поле. Ноль даёт прямые углы; геометрия фигур не меняется. |
| **Панель экспорта** | Страницы и их порядок собраны вместе, параметры бумаги и качества отделены. Список прокручивается, кнопки закрытия и сохранения остаются доступны, в том числе при открытой клавиатуре. [Проверки](docs/export-panel-design-checks.md). |
| **Углы фигур** | У прямоугольных фигур одинаковый радиус по горизонтали и вертикали. При масштабе от значения в настройках плагина (по умолчанию 200%; 0 — любой масштаб) потяни метку с уголком и двунаправленной стрелкой пальцем, стилусом или мышью: метка движется вместе с радиусом, а сверху показывается его текущее значение. Нажми метку для точного ввода; регулировку можно выключить в настройках плагина. Новые фигуры при нажатии имеют пропорции каталога, а при рисовании — заданные рукой размеры. |
| **CSS-сниппеты** | Поддерживаемые сниппеты Obsidian по умолчанию не влияют на доски. Нужные можно разрешить в доступных поиску настройках; заметки и выбранная тема сохраняют оформление. |
| **Просмотр и слайды** | Меню редактирования и создания скрыты; у выделенной веб-ссылки остаётся кнопка открытия. Указка включается в панели просмотра или показа. «Начать показ» использует фреймы в порядке файла, а при их отсутствии — страницы экспорта. В просмотре можно перемещать холст пальцем, начиная жест прямо на карточке или выделении; положение элементов и история сохраняются. |
| **Векторный PDF/PowerPoint** | Выбор «Растровый / Векторный» в экспорте. В PDF встроен Noto Sans; в PowerPoint — SVG на каждом слайде и запасное изображение для старых просмотрщиков. |
| **Векторный экспорт** | Фигуры, линии и текст сохраняются в SVG, страницы располагаются вертикально и обрезаются по своим границам. Растровые вложения остаются изображениями. |

SVG ссылается на установленные шрифты и не сохраняет декоративные тени.
Неподдерживаемое сложное содержимое вызывает явный отказ: в том числе PDF,
живые встраивания, маркеры списков и сложный или повёрнутый HTML-текст.
[Границы SVG и проверки](docs/vector-export-checks.md).
Изоляция сниппетов поддерживает обычные селекторы, условные правила,
наследование и `!important`. Импорты, определения шрифтов/анимаций/свойств,
непроверенные стили отдельных окон и изменения внешних предков доски
изолируются не полностью: появляется уведомление, сниппет может продолжать
влиять на Canvas. [Границы сниппетов и проверки](docs/canvas-snippet-checks.md).

Поиск по свойствам и тегам дополняет штатные результаты для
положительных условий, соединённых пробелами, например
`tag:project [status:"active"]`. OR, отрицание, регулярные выражения и смешанные
запросы по тексту/пути это дополнение не обрабатывает; штатный поиск продолжает
работать. Обратные ссылки только из свойств показываются при пустом фильтре
панели и открывают настоящую доску без выдуманных смещений текста. Неподдерживаемые
API, синтаксис и пределы сканирования могут отключить дополнение. Свойства Canvas
не превращаются в нативный Markdown frontmatter.

На Windows, планшете и смартфоне проверены ввод запроса по свойству и переходы
к настоящей доске и заметке. На SM-A336E с Obsidian 1.12.7 также проверены
жесты, темы и независимый экспорт; эта версия ниже поддерживаемого минимума.
[Результаты и различия способов ввода на телефоне](docs/smartphone-enhancement-checks.md).

[Поведение, хранение и оставшиеся проверки](docs/miro-canvas.ru.md#расширение-canvas--030)

## Установка

Нужен **Obsidian 1.13.7 или новее**. Публикация в каталоге ещё ожидается;
используйте BRAT или ручную установку. Проверки в настоящем приложении есть
для Windows и Android; iOS, macOS и Linux пока не проверены.
[Результаты проверок](docs/lint-remediation-checks.md).

### Через BRAT

1. В **Настройки → Сторонние плагины** установите и включите **BRAT** от
   **TfTHacker**. Если плагины заблокированы, выйдите из ограниченного режима.
2. Откройте палитру команд и выполните **BRAT: Plugins: Add a beta plugin for
   testing (with or without version)**.
3. Вставьте в поле **Repository** и нажмите Tab:

   ```text
   NixWrk/Obsidian-Plugin---Miro-Canvas
   ```

4. Выберите **Latest version**, оставьте **Enable after installing the plugin**
   и нажмите **Add plugin**.

Автоматические обновления управляются настройками BRAT. Выпуски `fonts-…`
содержат наборы шрифтов, а не сам плагин.

### Вручную

Скачайте **`main.js`**, **`manifest.json`** и **`styles.css`** из
[последнего выпуска](https://github.com/NixWrk/Obsidian-Plugin---Miro-Canvas/releases/latest).
Поместите их в `<хранилище>/.obsidian/plugins/miro-canvas/` и включите
**Miro Canvas** в сторонних плагинах. Для обновления замените эти три файла.

## Быстрый старт

1. Откройте или создайте доску Canvas.
2. Выберите **Стикер** (`N`) и нажмите на пустое место, чтобы записать идею.
3. Перетащите заметку из хранилища на доску.
4. Выберите **Линии и стрелки** (`L`) и соедините две карточки.
5. Выделите карточку, чтобы изменить цвет, шрифт или фигуру.

Для знакомства откройте **доску знакомства** при первом запуске или
создайте её через **Настройки → Miro Canvas → Начало работы → Создать
доску знакомства**. Внутри — примеры, которые можно редактировать,
настоящие заметки и образцы PDF/PowerPoint. Новая копия сохраняет прежние
доски и ваши изменения.

Горячие клавиши работают, когда вы не редактируете текст:

| Клавиша | Инструмент |
| --- | --- |
| V | Выделение |
| T | Текст |
| N | Стикер |
| S | Фигура |
| P | Перо |
| L | Линия |
| C | Комментарий |
| F | Фрейм |

**Escape** убирает инструмент. **Ctrl + Z** / **Cmd + Z** отменяет действие.
[Продолжить знакомство в наглядном руководстве →](docs/guide.ru.md)

## Перенос готовой доски

- **Из Miro:** создайте файлы хранилища отдельной программой
  [miro2obsidian](https://github.com/NixWrk/Miro_2_Obsidian), затем откройте
  доску с Miro Canvas.
- **Из Excalidraw, Enhancing Mindmap, Markmind или Advanced Canvas:** выберите
  **Импортировать в доску** в меню файла или палитре команд. Посмотрите
  предварительный просмотр; исходный файл сохраняется.

Часть оформления и расположения передаётся приблизительно. Таблицы из Miro
приходят без текста ячеек: его нет в используемой выгрузке.
[Инструкции и ограничения импорта](docs/import.ru.md).

## Файлы и приватность

Доски хранятся в вашем хранилище. С выключенным плагином обычный Canvas
открывает штатные карточки, заметки и связи. Для отображения оформления,
рисунков, комментариев и свободных линий нужен Miro Canvas. Исходные данные
импортированной доски Miro сохраняются при редактировании.

Редактирование работает без интернета. Сам плагин обращается к сети только
для проверки выпуска на GitHub — не чаще раза в день при запуске
(**можно отключить**) — и загрузки набора шрифтов по кнопке **Скачать**.
Проверка сообщает об обновлении, но не устанавливает его. Учётная запись,
оплата не требуются. Рекламы и телеметрии нет.

При добавлении файлов устройства, своих шрифтов и локальном импорте плагин
читает только выбранные вами файлы и копирует нужные данные в хранилище;
внешние папки не сканирует. Веб-ссылки и встраивания могут обращаться к своим
сайтам через Obsidian. BRAT, Sync и другие плагины используют сеть по своим
правилам.

Соединения линий с другими линиями экспериментальные и по умолчанию выключены.
Перенос большого выделения на досках с тысячами карточек может быть медленным.

### Работа с репозиторием через ИИ-агента

Начните с [AGENTS.md](AGENTS.md) и [руководства для разработчиков](docs/contributing.ru.md),
включая правила выпуска, шрифтов и записи GIF. Для интерфейса есть
[DESIGN.md](DESIGN.md); перед исправлениями линтера запишите затронутые
действия в [реестр проверок](docs/lint-remediation-checks.md).

Для разработки нужен Node **22.13+** в поддерживаемых ветках 22/24/26:

```bash
npm ci
npm run check
npm test
npm run build
```

Для чтения и изменения досок агентами есть отдельные [CLI и MCP-сервер](mcp/README.md)
и [навык miro-canvas-format](.agents/skills/miro-canvas-format/SKILL.md).
Готовые программы доступны в последнем выпуске; для них нужен **Node 20+**.
Запускайте их отдельно, вне папки плагина. Сам плагин их не запускает.

[Примечания о совместимости](docs/contributing.ru.md#оставшиеся-предупреждения-исходного-кода)
объясняют импорты Node для этих программ, стандартную папку `.obsidian`
и сохранение ID команды ради настроенных горячих клавиш.
