## Как это выглядит

Вы открываете файл `.canvas` как обычно - это по-прежнему Canvas Obsidian, со
своими карточками, ссылками, файлами и историей, - а доска работает как доска
Miro:

- **Внизу** - панель инструментов: выделение, текст, стикер, фигура, перо,
  линии и стрелки, комментарий, фрейм, а также карточка, заметка и файл из
  хранилища самого Canvas. У каждого инструмента Miro своя буква, как в Miro.
- **Над выделенным** - панель форматирования, устроенная как в Miro: фигура,
  шрифт, начертание, цвета, комментарий, блокировка.
- **В углу** - миникарта и небольшая угловая панель с отменой, масштабом и
  меню доски.

Доска, перенесённая из Miro, сохраняет свой вид: стикеры в цветах Miro с
подогнанным текстом, фигуры и блок-схемы, фреймы, блоки кода, превью ссылок,
презентации со слайдами и комментарии там, где они стояли.

Выключенный плагин ничего не теряет: файл открывается как обычный Canvas. В
сеть плагин ходит только за двумя вещами, обе описаны в разделе
[Сеть](#сеть).

## Что из Miro, а что из Obsidian

Miro Canvas - не копия Miro внутри Obsidian. Доска остаётся собственным Canvas
Obsidian - его файлом, его карточками, его ссылками, - а плагин переносит на
неё то, как работают в Miro.

| | Взято из Miro | Осталось от Canvas Obsidian |
| --- | --- | --- |
| **Доска** | Панель инструментов внизу, буква у каждого инструмента, панель форматирования над выделенным, миникарта | Файл `.canvas` в вашем хранилище, который открывается и без плагина; прокрутка, масштаб, выделение, отмена и повтор, копирование и вставка |
| **Что на ней** | Стикеры, фигуры и фигуры блок-схем, фреймы с названиями, блоки кода, таблицы, комментарии | Карточки, заметки, картинки, PDF и другие файлы из хранилища, веб-страницы, группы |
| **Текст** | Шрифт, размер, полужирный, курсив, подчёркнутый, зачёркнутый, выравнивание, цвет, маркер, список и ссылка - с одной панели; шрифты Miro для скачивания | Markdown в каждой карточке, со ссылками, встраиваниями, формулами и всем остальным, что Obsidian показывает в заметке |
| **Линии и стрелки** | Прямые, угловые, изогнутые, широкие стрелки, ломаные и плавные кривые; концы где угодно на доске; подписи со своим шрифтом | Линия между двумя карточками - по-прежнему собственная связь Canvas |
| **Рисование** | Перо, маркер, умное рисование, ластики | - |
| **Порядок и блокировка** | На передний план, вперёд, назад, на задний план; сдвинутая карточка сохраняет свой слой; блокировка | - |
| **Комментарии** | Где угодно, с обсуждениями, ответами, авторами и отметкой «решено» | - |
| **Экспорт** | Отмеченные на доске страницы или слайды презентации - в PDF или PowerPoint | Каждая страница снимается так же, как собственный **Экспорт в изображение** Canvas |
| **Вид** | Цвета Miro для стикеров и фреймов | Цвета и шрифты темы Obsidian |

Чего нет ни там, ни там и что добавлено здесь:

- **Панели там, где удобно** - нижнюю панель, угловую панель и миникарту
  можно поставить к любому краю или в любой угол, а панели - повернуть
  столбцом.
- **Создание перетаскиванием** - любой инструмент, который создаёт элемент,
  можно перетащить с панели на доску, как собственные кнопки карточки,
  заметки и файла в Canvas.
- **Свои шрифты** - наборы шрифтов для скачивания, свои файлы шрифтов и
  единый список шрифтов, которые вы хотите видеть.
- **Доски Miro в вашем хранилище** - отдельная бесплатная программа
  переносит доски целиком, с их видом; данные Miro едут вместе с ними
  нетронутыми.
- **Доска знакомства**, где каждый инструмент показан на настоящих элементах.
- **Описанный формат файла** - всё, что добавляет плагин, лежит под одним
  ключом файла Canvas и следует опубликованной схеме, так что его могут
  читать другие программы и ИИ-агенты.

## С чего начать

1. Установите и включите плагин (см. [Установка](#установка)).
2. Откройте любой файл `.canvas` или создайте новый.
3. Выберите инструмент внизу или нажмите его букву: **V** выделение, **T**
   текст, **N** стикер, **S** фигура, **P** перо, **L** линии и стрелки, **C**
   комментарий, **F** фрейм.
4. Щёлкните по доске, чтобы поставить элемент, - или нажмите на кнопку
   инструмента, потяните на доску и отпустите там, где он должен стоять.
5. Выделите элемент, чтобы оформить его.

Блок кода, таблица и ссылка начинают в меню **+** в конце панели. Настройки →
Miro Canvas → **Нижняя панель** решает, какие инструменты стоят на панели и в
каком порядке; остальные остаются в меню **+**.

При первом запуске плагин предложит **доску знакомства** - двенадцать фреймов,
где каждый инструмент показан на настоящих элементах: текст разными шрифтами и
начертаниями, цвета и маркер, стикеры, фигуры и блок-схема, линии всех стилей,
рисование, слои, комментарии, код и таблицы, заметка и другие файлы, страницы
экспорта, - и спросит, хотите ли вы перенести доски из Miro. Любой ответ
подходит: и доска, и руководство останутся в Настройки → Miro Canvas →
**Начало работы**. Создание доски заодно создаёт рядом небольшую папку с
образцами файлов (заметку, мини-холст, картинку, PDF и документ Word), поэтому
её фрейм «Файлы и заметки» всегда показывает настоящие файлы.

## Элементы на доске

- **Стикеры** - квадратные заметки в цветах Miro. Текст уменьшается, чтобы
  поместиться в стикер, как в Miro.
- **Текст** - текст без карточки под ним, начинается там, где вы щёлкнули.
- **Фигуры** - прямоугольники, круги, треугольники, звёзды, облака, стрелки и
  другие, и полный набор блок-схем: начало и конец, решение, документ, база
  данных, ручной ввод, задержка и остальные. Подсказка над фигурой в палитре
  говорит, что она значит в блок-схеме. Текст стоит внутри фигуры.
- **Фреймы** - именованные области, которые держат другие элементы и
  двигаются вместе с ними. Они всегда лежат под карточками.
- **Блоки кода** - код на тёмной панели с заголовком, как Miro показывает
  код.
- **Таблицы** - таблица Markdown в карточке.
- **Ссылки** - веб-страница на доске, так, как её показывает Canvas.
- **Карточки, заметки и файлы из хранилища** - собственные элементы Canvas,
  со своими кнопками на панели: карточка Markdown, заметка, картинка, PDF,
  другой холст, любой файл.
- **Комментарии** - см. [Комментарии](#комментарии).

У одного выделенного элемента появляются ручки, которых нет в Canvas: круглая
ручка под ним поворачивает его (с **Shift** - шагами по 15°), а стрелка с
каждой стороны щелчком добавляет рядом новый элемент, уже соединённый с этим,
а перетаскиванием проводит от него линию.

Копирование, вырезание и вставка сохраняют всё, что плагин знает об
элементе: его вид, фигуру, поворот - и внутри доски, и между досками.
Вставленный файл по-прежнему указывает на тот же файл в хранилище; ничего не
дублируется.

Каждое изменение - один шаг отмены.

## Оформление выделенного

Выделите что-нибудь - над ним появится панель в том же порядке, что и в Miro:

- **Фигура** - превратить карточку в другую фигуру.
- **Шрифт и размер** - шрифты из вашего списка шрифтов (см. [Шрифты](#шрифты)).
- **Начертание** - полужирный, курсив, подчёркнутый, зачёркнутый;
  выравнивание по левому краю, по центру, по правому краю или по ширине, и
  сверху, посередине или снизу; межстрочный интервал.
- **Маркированный список** и **Ссылка** - ссылка превращает весь текст или
  выделенную часть в ссылку Markdown.
- **Цвета** - цвет текста, маркер, заливка; цвет рамки, её вид (сплошная,
  пунктирная, точечная или без рамки) и толщина.
- **Комментарий** - приколоть комментарий к выделенному.
- **Блокировка** - см. [Блокировку](#блокировка-и-режим-просмотра).
- **Ещё** - порядок, приближение к выделенному, редактирование, удаление.

Линия или стрелка вместо этого показывает на том же месте свои элементы: два
конца, вид линии, толщину, размер наконечника, цвет и подпись.

## Рисование, линии и стрелки

- **Перо, маркер, умное рисование** - штрих становится отдельным элементом
  доски. Умное рисование превращает кривую фигуру в ровную, а кривую линию - в
  стрелку. С **Shift** штрих идёт прямо.
- **Ластики** - стирают штрих целиком или только часть под указателем.
- **Со стилусом** сила нажатия задаёт толщину линии, а ладонь, лежащая на
  экране, не мешает; пока выбран инструмент рисования, палец прокручивает
  доску.
- **Линии и стрелки** - прямые, угловые, изогнутые, широкие стрелки, ломаные и
  плавные кривые. Линия, оба конца которой на карточках, - обычная связь
  Canvas; линия с концом где-то ещё - на пустом месте или на другой линии -
  хранится плагином. Разницы вы не заметите: обе выделяются, оформляются,
  подписываются, копируются и удаляются одинаково.
- Концы прилипают к контуру карточки и её ключевым точкам; потяните за середину
  линии, чтобы изогнуть её.
- Шрифт подписи - гарнитура, размер, полужирный, курсив, подчёркнутый,
  зачёркнутый - задаётся той же панелью, что и текст карточки, и сохраняет
  размер текста карточки при любом масштабе.

## Что поверх чего

Карточки можно переместить на передний план, вперёд, назад и на задний план -
из **Ещё** на панели форматирования, из контекстного меню карточки или
командами, которым можно назначить клавиши. Это работает для всего выделения и
сохраняет порядок карточек между собой; одна отмена возвращает всё.

**Вперёд** и **назад** проводят карточку мимо ближайшей карточки, которая её
перекрывает. Фреймы всегда лежат под карточками, как их рисует Canvas, а у линий
порядка нет. Как в Miro, перетаскивание и выделение не поднимают карточку наверх.

## Комментарии

Комментарий можно приколоть куда угодно: к карточке, к точке на картинке, к
линии или к пустому месту доски. У обсуждений есть ответы, авторы со своими
цветами, отметка «решено» и блокировка. Комментарии из Miro остаются только
для чтения, и их можно скрыть. Отдельная панель показывает все комментарии
доски или выделенного.

## Блокировка и режим просмотра

Заблокированный элемент нельзя двигать, менять размер, поворачивать, править
текст, оформление, соединения или удалять, пока его не разблокируют. **Режим
просмотра** блокирует всю доску, оставляя прокрутку, выделение, ссылки,
копирование и комментарии.

## Угловая панель и миникарта

- **Отмена и повтор**, кнопка, которая показывает или прячет **миникарту**,
  и масштаб.
- **Процент масштаба** открывает меню вида: показать всю доску, масштаб 50 %,
  100 % или 200 %, миникарта, привязка к сетке и к объектам.
- **Шестерёнка** открывает меню доски: тема доски (как в системе, светлая или
  тёмная), экспорт в PDF или PowerPoint, режим просмотра, имена у всех
  вложений или только у выделенного, команды плагина, сведения об источнике
  перенесённой доски, настройка панелей и настройки плагина.
- **Миникарта** показывает всю доску; щёлкните или потяните в ней, чтобы
  перейти в это место.

## Настройка панелей на доске

В меню доски (шестерёнка в угловой панели) есть пункт **Настроить панели**,
и такая же команда. Она включает режим с плашкой сверху:

- Нижнюю панель, строку значков угловой панели или миникарту можно
  перетащить в новый угол или к краю. Каждая остаётся внутри вида и на своём
  месте при любом размере окна и переходит в вертикальный вид у бокового
  края.
- Нижнюю панель и строку значков угловой панели можно повернуть между
  строкой и столбцом маленькой кнопкой рядом с ручкой, у какого бы края они ни
  стояли. Вертикальная панель открывает свои меню в сторону, к середине
  доски.
- Инструмент на нижней панели можно перетащить, чтобы переставить его,
  вынести с панели на доску - он попадёт в лоток, - или вернуть из лотка на
  панель. Это пишет ту же настройку **Нижняя панель**, что и вкладка
  настроек, так что годится любой способ.

**Вернуть как было** в плашке возвращает всё по умолчанию; **Готово**, Escape
или переход на другую доску выключают режим. Панель форматирования всегда
следует за выделением.

## Перенести доски из Miro

Перенос делает отдельная бесплатная программа,
[miro2obsidian](https://github.com/NixWrk/Miro_2_Obsidian), для Windows, macOS и
Linux. Плагин её не скачивает, не устанавливает и не запускает - он только
показывает дорогу:

1. **Установите miro2obsidian** - готовую сборку из её
   [выпусков](https://github.com/NixWrk/Miro_2_Obsidian/releases/latest).
2. **Или доверьте это ИИ-агенту** - Codex или Claude Code сделают все шаги со
   скиллом `miro2obsidian-import`; руководство даст готовый запрос с путём к
   этому хранилищу.
3. **Создайте своё приложение Miro** - один раз, 10-20 минут, без
   программирования; этого требует модель безопасности Miro.
4. **Выгрузите доску в это хранилище** в формате **miro-canvas**.
5. **Откройте доску** здесь.
6. **Удалите программу**, если хотите, - доскам она не нужна.

Руководство - в Настройки → Miro Canvas → **Открыть руководство по импорту**.

## Экспорт в PDF и PowerPoint

**Экспорт в PDF или PowerPoint** в меню доски отмечает на доске страницы -
прямоугольники одного формата бумаги (A4, A3, Letter, 16:9, 4:3 или произвольный),
которые двигаются за ярлык и растягиваются за угол. Они хранятся вместе с
доской, но не становятся карточками, так что на доске ничего не меняется.
**Страница на каждый фрейм** добавляет страницу вокруг каждого фрейма. У
презентации свой экспорт, где страницы - её слайды. Каждая страница снимается
так же, как собственный **Экспорт в изображение** Obsidian, и собирается в PDF
или презентацию PowerPoint; небольшое окно показывает ход и позволяет
остановить.

## Шрифты

Карточки, стикеры и линии уже предлагают шрифты, которые есть на любой машине,
и шрифты самого Obsidian. Настройки → Miro Canvas → **Шрифты** добавляют
больше:

- **Наборы шрифтов** - собственный список шрифтов Miro, его японские и
  корейские шрифты, открытые шрифты с метриками Calibri, Cambria, Arial,
  Times New Roman, Courier New и Georgia из Word, и шрифты, которыми рисует
  Excalidraw. «Скачать» устанавливает набор, «Удалить» убирает его обратно, и
  то и другое - с показом хода загрузки. Доска, перенесённая из Miro, или
  доска, нарисованная в Excalidraw, может уже называть эти шрифты; набор
  делает так, чтобы она отображалась именно в них.
- **Свой файл шрифта** - «Добавить файл шрифта» копирует файл `.ttf`, `.otf`,
  `.woff` или `.woff2` в собственную папку плагина; его имя можно изменить, а
  «Удалить» убирает файл обратно.
- **Список шрифтов** - какие шрифты предлагает всплывающий список шрифтов на
  панели форматирования и в каком порядке; переключатель убирает шрифт из
  списка, не удаляя его.

См. [Сеть](#сеть): ничего не скачивается, пока вы не нажмёте «Скачать».

## Файл остаётся Canvas

Всё, что умеет выразить Canvas, остаётся в его собственных полях. Чего не умеет -
шрифты, цвета, фигуры, поворот, блокировки, комментарии, свободные линии,
страницы экспорта - хранится под одним дополнительным ключом `miroCanvas`,
который Canvas пропускает. В доске, перенесённой из Miro, есть ещё `miroSource` -
данные Miro в том виде, в каком их выгрузили; плагин их читает и никогда не
меняет.

Формат записан версионированной JSON Schema, которую ведёт miro2obsidian; этот
репозиторий хранит её закреплённую копию в [`schema/v1`](schema/v1), и его тесты
прогоняют все её примеры досок. Агенты могут читать и безопасно править доски со
скиллом `miro-canvas-format` из miro2obsidian.

## Языки

Плагин говорит по-английски и по-русски. Он берёт язык, на котором говорит сам
Obsidian, а для остальных языков - английский.

## Ограничения

- **Экспорту в PDF и PowerPoint нужен Obsidian на компьютере**; на телефоне и
  планшете работает всё остальное, экспорт - нет.
- **Таблицы из Miro приходят пустыми**: экспорт Miro не содержит текста ячеек.
- Линии, прикреплённые к другим линиям, - **экспериментальные** и по умолчанию
  выключены.
- Очень большие доски (тысячи карточек) остаются отзывчивыми, но перетаскивание
  множества карточек сразу медленнее, чем в Miro.
- Плагин Advanced Canvas не нужен; доски, сделанные для него, здесь тоже
  открываются.

## Сеть

Раз в день, при запуске Obsidian, плагин узнаёт у GitHub номер последнего
выпуска этого плагина, чтобы новая версия появилась в строке состояния вместе
с описанием. Больше ничего не отправляется, ничего не скачивается, и плагин
никогда не обновляет себя сам. Выключается в Настройки → Miro Canvas →
Обновления; кнопка **Проверить** там же проверяет по запросу.

Наборы шрифтов (см. [Шрифты](#шрифты)) приходят из выпуска собственного
репозитория этого плагина на GitHub. Ничего не скачивается, пока вы не
нажмёте «Скачать» в Настройки → Miro Canvas → Шрифты, а удаление набора
удаляет только файлы, записанные самим плагином.

## Установка

В каталоге сторонних плагинов Obsidian его пока нет. Проще всего установить
его и получать обновления через **BRAT** - плагин, который ставит другие
плагины прямо из их выпусков на GitHub:

1. В Obsidian откройте Настройки → Сторонние плагины. В хранилище, где их
   ещё не было, сначала нажмите **Выйти из ограниченного режима**.
2. Нажмите **Обзор**, найдите **BRAT** и выберите тот, у которого автор
   **TfTHacker**, - у других плагинов похожие названия, - затем нажмите
   **Установить** и **Включить**.
3. Откройте палитру команд (Ctrl+P, на Mac - Cmd+P), наберите
   `add a beta plugin` и выполните **BRAT: Plugins: Add a beta plugin for
   testing (with or without version)**.
4. Вставьте `NixWrk/Obsidian-Plugin---Miro-Canvas` в поле **Repository** и
   нажмите Tab. В списке **Select a version** выберите **Latest version** -
   строки `fonts-…` там хранят наборы шрифтов, а не плагин, - оставьте
   включённым **Enable after installing the plugin** и нажмите
   **Add plugin**.

У BRAT с самого начала включено **Auto-update plugins at startup**, так что
каждый новый выпуск приходит при следующем запуске Obsidian; команда
**BRAT: Plugins: Check for updates to all beta plugins and UPDATE** делает
это по запросу. Собственная проверка обновлений плагина (см. [Сеть](#сеть))
только сообщает, что вышла новая версия; с BRAT она приходит сама.

BRAT спрашивает GitHub о выпусках, а без токена GitHub отвечает на 60 таких
вопросов в час с одной сети. Если BRAT пишет, что лимит превышен (rate limit
exceeded), подождите названное им число минут и попробуйте снова.

**Вручную**: скачайте `main.js`, `manifest.json` и `styles.css` из
[последнего выпуска](../../releases/latest), положите их в
`<хранилище>/.obsidian/plugins/miro-canvas/` и включите **Miro Canvas** в
Настройки → Сторонние плагины. Новая версия ставится так же.

## Разработка

```bash
npm install
npm run dev            # сборка с отслеживанием изменений
npm run build          # итоговая сборка в корень репозитория
npm test               # модульные тесты
npm run check          # tsc --noEmit
npm run schema:check   # закреплённая копия схемы совпадает с miro2obsidian
```

В `tools/obsidian_oracle` - проверки в браузере на искусственном Canvas и
скрипты для проверки в настоящем хранилище Obsidian; им нужны Python, Playwright
и miro2obsidian (`pip install -r requirements-dev.txt`, затем
`python -m playwright install chromium` и
`python -m tools.obsidian_oracle.smoke_plugin_ui`). Наборы шрифтов собирает
`tools/build_font_packs.py`, а выпускает метка `fonts-0.0.N`. Агентам, работающим с
этим репозиторием, - начинать с [AGENTS.md](AGENTS.md); заметки об устройстве и
список задач - в [docs/miro-canvas.ru.md](docs/miro-canvas.ru.md).
